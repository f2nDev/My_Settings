# My_Settings

**install the tools and VS Code settings** that I use when working on pwn genre projects. If any additional items need to be installed, I will add them as appropriate.

## overview

This **installs the tools and settings** I normally use. It is recommended when you want to set up a new environment.

## Required environment

- **Python**
- **Debian-based Linux**
- **VS code**

## What gets installed with this

- **Python venv**
- **pwntools**
- **pwndbg**
- **Docker**
- **ghidra**
- **VS Code extensions**

## Installation

Clone this repository and navigate to the directory.

```bash
git clone https://github.com/f2nDev/My_Settings
cd My_Settings
```

## Usage

you want to install tools for the pwn category:

```bash
chmod +x ./pwn-build.sh
sudo ./pwn-build.sh
```

you want to install VS Code extensions

```bash
chmod +x ./vscode-build.sh
./vscode-build.sh
```
